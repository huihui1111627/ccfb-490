# 清式斗拱参数化建模与 WebGL2 渲染系统

浏览器端斗拱(斗栱)参数化建模工具。按清式《工程做法则例》斗口制,以斗口 d 为唯一基本模数
驱动全部构件尺寸;TypeScript + 原生 WebGL2 实现,不依赖任何三维引擎或外部图片资源。

## 功能页签

| 页签 | 能力 |
| --- | --- |
| 构件库 | 坐斗、翘、昂、瓜拱、万拱、厢拱、三才升/槽升子、十八斗、枋,九类构件单独预览;份数→毫米换算表 |
| 斗拱组合 | 三踩/五踩/七踩/九踩 × 平身科/柱头科/角科自动组装;线框、SSAO、阴影、爆炸视图;构件清单点击高亮 |
| 整殿预览 | 矩形柱网 + 平板枋 + 檐檩 + 周边斗拱(四角角科、柱顶柱头科、柱间均布平身科),改斗口全殿线性联动 |
| 材质彩画 | 程序化木纹(纤维/年轮/木节)与旋子彩画(找头旋花/枋心/箍头),Canvas2D 现场生成,基色可调 |
| 导出与方案 | 构件清单 CSV、模型 OBJ(单攒/整殿)、localStorage 方案版本管理与两版参数 diff |

## 清式斗口制尺寸体系(全部为 d 的倍数)

- 足材高 2d、单材高 1.4d、一拽架 3d
- 翘长 7/11/15/19d,昂长 13/17/21d;瓜拱 6.2d、厢拱 7.2d、万拱 9.2d
- 坐斗 3d 见方、十八斗 1.8d、三才升 1.3d
- 踩数与出跳:n =(踩数−1)/2,出跳距离 = 3d × n
- 同层十字相交构件以半榫槽口搭接,槽口由分块盒体直接拼出,无布尔运算、实体零穿插

所有尺寸在生成阶段乘以实际斗口毫米数,因此严格线性:同一攒在任意斗口下形状不变,
浮点误差 < 0.01mm(见 `tests/node-smoke.ts` 核验)。

## 渲染管线

GBuffer MRT(视空间位置/法线/反照率)→ 阴影深度图(3×3 PCF)→ SSAO(32 核半球采样
+ 5×5 模糊)→ 前向光照合成(方向光、环境光、Reinhard 色调映射、gamma)。
浮点渲染目标不可用时自动回退到 RGBA8 视空间深度编码,兼容 SwiftShader/集显。

## 命令

```bash
npm install
npm run dev      # 开发服务器
npm run build    # tsc 类型检查 + vite 生产构建
npm run smoke    # 尺寸线性/毫米精度/无穿插/全踩数全科型 核验
```
